backupmgr – Privacy policy

backupmgr is a personal backup tool used only by its owner. It has no other users.

Google user data accessed

backupmgr requests only the https://www.googleapis.com/auth/drive.file scope. With this scope, it can only create, read, list and delete the files it uploads itself: encrypted backup archives. It cannot see or access any other file in the Google Drive account.

How the data is used

The files are encrypted before upload and are stored in Google Drive solely to keep an off-site copy of the owner's own backups. Old archives are deleted automatically by the tool to stay within the storage quota.

Storage and sharing

The access token is stored only on the owner's private server. No Google user data is shared with, sold to, or transferred to any third party, and no data is used for advertising or analytics.

Revoking access

Access can be revoked at any time from the Google Account security settings (Third-party apps with account access).
