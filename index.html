backupmgr

backupmgr is a personal backup tool used by a single person on a private home network. Once a week, it creates an encrypted archive of the owner's own server backups and stores it in a Google Drive account dedicated to that purpose.

It uses the Google Drive API with the drive.file scope only: it can access only the files it creates itself, and never reads any other file in the account.

This is not a public service and it has no other users.
